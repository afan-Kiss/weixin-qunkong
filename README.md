# 微信群控

桌面端微信群控管理平台（Electron + Vue3 + TypeScript）。通过本机 Hook 接口完成多开微信、群成员采集、加好友、二维码进群、消息群发等操作。

## 功能说明

### 群聊实时发言加好友（需求 1）

**入口**：左侧导航 → **群聊加好友**

1. 选择在线微信，多选监听群。
2. 关键词可留空（全量发言），或多个关键词（OR 命中）。
3. 排除 WXID / 昵称（精确匹配）。
4. **开启监听** → 命中后进候选。
5. **勾选候选** → **创建加好友任务** → **任务中心**确认执行。
6. 频繁时状态显示 **已经频繁**。

### 群成员 / 最新入群加好友（需求 2、7）

**入口**：**群与成员**

- 支持「从第几个开始」「最大人数」「排除规则」。
- 群列表按群 ID **跨微信汇总去重**。
- 采集最新入群后须**勾选成员**再创建任务。
- 频繁状态：**已经频繁**。

### 二维码采集与进群（需求 3、4）

**入口**：**二维码任务**

- 历史图片采集 / 群消息监控：自动识别并分类保存到「微信群二维码 / 微信个人二维码 / QQ群二维码」子目录。
- 历史消息内容若为 WCDB zstd 压缩（Base64 `KLUv/…`），采集前会自动解压再 CDN 下载；监控在微信重启后按群 ID 自动重绑实例。
- **同图多码**：一张图同时含微信群码与 QQ 群码时，两类都会分别保存（按内容哈希去重，不会互相覆盖）。
- 文件名：`类型_群名_消息ID_时间_内容哈希前12位.扩展名`。
- 批量导入链接：勾选群链接后创建进群任务；个人码可跳过；进群后可选保存通讯录。
- **进群前预览**：创建任务前用 `get_a8key` 解析并展示群名、人数、群 ID；短链会尽量换成完整邀请链接再 `enter_room`。
- **进群成功判定**：不再把「HTTP 成功 + 空 data」当成已进群；未返回群标识记为失败并在任务说明中写明原因。
- 进群频繁：任务项状态 **已经频繁**，任务进入冷却。

### 消息群发（需求 5、6）

**入口**：**消息群发**

- 好友 / 群聊两个页签；支持文字 + 图片；排除 WXID / 昵称；须勾选目标后创建任务。

### 通讯录保存（需求 9）

**入口**：**通讯录** → 未保存群 → 勾选 → 保存到通讯录。

### 风控（需求 11）

- 全局随机间隔（秒）
- 每微信每日加好友上限
- 每微信每日进群上限（二维码任务配置）
- 频繁冷却分钟数
- 相同内容跳过（群发）

### 群选择下拉（搜索 / 全选 / 流畅度）

适用页面：**群聊加好友**、**群与成员**、**二维码任务**。

- 标题行提供「全选」，与下拉框分排，避免重叠。
- 下拉支持输入搜索（群名 / 群 ID，不区分大小写）；搜索词 **120ms 防抖**。
- 选项限量渲染（空搜约 80 条、有搜约 120 条），已选项始终保留显示；提示「继续输入可精确匹配」。
- 展开下拉时跳过候选刷新；群聊加好友候选轮询约 **12s**；侧栏指标约 **5s**；任务/进度约 **3s**，减轻卡顿。
- 「操作失败」气泡：IPC 不可克隆对象已净化；克隆类错误只记日志；同文案 **4s** 内不重复弹窗。

## 换电脑使用（推荐便携包）

**不要只拷源码目录去另一台机直接跑**，请先在本机打便携包：

```bash
cd admin-ui
npm run package:portable
```

产物在 `admin-ui/release/微信群控系统v*.exe`（便携版，免安装）。

### 新电脑要求

1. Windows 10/11，已安装 **微信 PC 版（Weixin.exe）**
2. 能访问授权服务器（登录账号需要联网）
3. 首次打开后：软件会自动探测微信路径；找不到再到 **日志与设置 → 文件位置** 点「重新检测」
4. 登录账号 → 打开微信实例 → 再做加好友/进群等操作
5. 创建任务后必须到 **任务中心 → 确认执行**

### 打包自检

- 注入组件已放到 `admin-ui/resources/hook/4.1.8.27/`（`inject.exe` + `libGLESv1.dll`）
- 打包脚本会先执行 `npm run ensure:hooks`
- 代码不再依赖本机绝对路径（如 `E:\...`）

## 微信路径自动探测

软件启动时会从注册表与常见安装目录自动查找 `Weixin.exe` 并写入设置，无需手填。

- 已配置且路径有效：不覆盖
- 配置无效/为空：自动探测并保存
- 实在找不到：日志提示，到 **日志与设置 → 文件位置** 点「重新检测」或「手动选择」

## 静默更新（对齐开云链路）

桌面端通过 `electron/client-updater.cjs` 对接管理台「版本发布」：

1. **仅启动时检查** `/wxqk/api/update/manifest`（运行中不轮询，避免打扰正在使用的客户端；有更新才提示下载替换）
2. Ed25519 验签（与服务器 `publish_ed25519.priv` / `FACAI888_PUBLISH_KEY_B64` 配对）
3. 按 `releaseSequence` 判断是否需要更新；本地包 sha256 已一致则跳过（防循环）
4. HTTPS Range 断点续传 → 校验 sha256 → 替换便携包（`PORTABLE_EXECUTABLE_FILE`）→ 拉起新进程并退出旧进程

发布约定：

- 下载基址：`https://xiangyuzhubao.xyz/wxqk`
- 清单文件名：`微信群控系统vX.Y.exe`
- 打包时 `bump-version.cjs` 会递增 `package.json` 的 `wxqkReleaseSequence`（并尽量对齐远端序号+1）

请把便携包放在可写目录（如桌面）；开发模式只提示有更新，不自动替换。

## 远程桌面

桌面端通过 `electron/remote-agent.cjs` 推送 JPEG 画面到管理台。

- **流畅优先**：自适应帧间隔约 120–320ms（约 3–8 FPS），抓完再调度下一帧，避免堆积更卡
- **鼠标**：网络正常时合成箭头；拥塞时只传光标坐标以减轻 CPU
- **清晰度**：分辨率上限约 1280×720，JPEG 质量约 70（拥塞时自动降到约 42–55）

复测：重启本机软件并保持在线 → 管理台远程桌面开启查看，确认拖动窗口时明显更顺。
